Windows Shortcut Instructions:

1. Locate RunSolidarityConfigApp.bat in the SolidaritySystemConfigApp folder.
2. Right-click RunSolidarityConfigApp.bat and select "Create shortcut".
3. Move the shortcut to your Desktop or Start Menu for easy access.
4. Double-click the shortcut to launch the Solidarity System Config App.

Step-by-Step Run Instructions:

1. Make sure Java is installed (Java 8+). If not, download from https://www.java.com/en/download/
2. Open the SolidaritySystemConfigApp folder.
3. Double-click RunSolidarityConfigApp.bat to compile and run the app automatically.
4. The app window will open. Use the interface to manage system config, save encrypted logs, and desypher logs.

You can always re-run the shortcut to launch the app again.
