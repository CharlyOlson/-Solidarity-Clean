## Core Concepts

### Henry 7→14→49 Numerological System
The Solidarity Platform implements the **Henry 7 Step 14 Trott Waltz** numerological framework:
- **Base Ratio**: φ = 1.618033988749 (Golden Ratio)
- **Baseline**: 0.618 (safety level anchor)
- **Valid Nodes**: 1, 3, 4, 7, 14, 21
- **Sacred Sequence**: 7 → 14 → 49 (control ratio 3.5)
- **Recursion Depth**: 49 levels
- **Cubic Precision**: 64-bit

### Safety System
7-tier safety ranges ensure system stability:
- **0.00-0.05**: Emergency (critical)
- **0.05-0.15**: Warning
- **0.15-0.25**: Caution
- **0.25-0.75**: Optimal (includes 0.618 baseline)
- **0.75-0.85**: Upper Caution
- **0.85-0.95**: Upper Warning
- **0.95-1.00**: Critical Upper

### Technology Stack
- **Core Engine**: JavaScript (Node.js)
- **DSP Processing**: Python 3.8+
- **Frontend**: React with sacred geometry visualizations
- **AI Integration**: Ollama (local, default model: llama3.2:3b)
- **Financial**: Smart contracts, blockchain connectors (test-mode first)
- **Security**: JWT, bcrypt, helmet, rate limiting, input validation

## Getting Started

1. **Installation**
   ```bash
   npm install
   cd frontend && npm install && cd ..
   ```

2. **Configuration**
   - Copy `.env.example` to `.env`
   - Configure your environment variables

3. **Run the Platform**
   ```bash
   npm start                    # Start API server
   npm run quantum:demo         # Run quantum demo
   npm run test:bridging        # Test DSP processing
   ```

4. **Frontend Development**
   ```bash
   npm run frontend:dev         # Start frontend dev server
   ```

For detailed setup instructions, see [Quick Start Guide](./guides/QUICK_START.md).
