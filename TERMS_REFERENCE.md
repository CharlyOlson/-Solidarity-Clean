# Solidarity Platform - Terms & Definitions Reference

This file defines the official terms, labels, and naming conventions for the Solidarity Platform codebase. Use this as the single source of truth for naming, branding, and terminology. Update this file if any term changes or new terms are introduced.

---

## Core Terms

| Term                | Definition                                                                 |
|---------------------|----------------------------------------------------------------------------|
| Solidarity Platform | The official name of the application and UI. Use in all branding/headers.  |
| -Solidarity-Clean   | The repository name (with leading dash).                                   |
| main                | The main (default) git branch.                                             |
| Hanko Stamps        | The digital authentication stamp feature/tab.                              |
| Files               | The file/folder/repo navigation tab.                                       |
| Financial           | The financial graphing/analytics tab.                                      |
| Home                | The home/welcome tab.                                                      |
| Scott Charles Olson | Trademark owner and platform creator.                                      |
| Trademark           | "TRADEMARKED BY SCOTT CHARLES OLSON".                                     |
| clean               | Used in repo name and as a codebase quality/clarity indicator.             |

---

## Usage Guidelines

- Always use **Solidarity Platform** in UI headers, navigation, and documentation.
- The repository name is **-Solidarity-Clean** (with dash). Do not use spaces or other variants.
- The main branch is always **main**.
- Use the tab names exactly as listed above in navigation and UI.
- For new features, add terms here before using them in code or docs.

---

## Example Usage

- UI Header: `SOLIDARITY PLATFORM`
- RepoBrowser: `Repository: -Solidarity-Clean`, `Branch: main`
- Trademark: `© Scott Charles Olson - φ = 1.618`
- Tabs: `Home`, `Files`, `Hanko Stamps`, `Financial`
